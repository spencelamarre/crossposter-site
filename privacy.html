Privacy policy

Last updated November 5, 2026

Crossposter is a personal tool used only by its owner, on the owner's own accounts. It has no other users.

What it uses

When the owner connects an account, the platform issues a login token. Crossposter uses that token to publish the owner's videos and to read the statistics of the owner's posts and accounts.

Where it is kept

Tokens and statistics are stored on computers and storage the owner controls. Crossposter doesn't sell or share this data, and doesn't use it for advertising.

This website

This site has no cookies, analytics or forms. It is hosted by GitHub Pages, which may keep standard server logs. The login pages on this site only pass a platform's sign-in response back to Crossposter on the owner's computer.

Deleting data

Disconnecting an account in Crossposter deletes its stored token. Access can also be removed at any time in the platform's own app settings.

Contact

Questions can be sent through this site's GitHub page.
